# assistant

## Description

[⚠️ experimental feature] manage AI assistant settings (Rovo/Gemini)

## Usage

```
1Usage: forge assistant [options] [command]
2
```

## Options

```
1--verbose            enable verbose mode
2-h, --help           display help for command
3
```

## Commands

```
1on [options] <name>  [⚠️ experimental feature] enable AI assistant for error
2                     analysis (specify name: rovo or gemini)
3                     When errors occur during Forge command execution, error
4                     details will be sent to your AI agent to help you
5                     understand and resolve issues.
6off [options]        disable AI assistant for error analysis
7
```
