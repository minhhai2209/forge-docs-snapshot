## Usage

```
1Usage: forge module list [options]
2
```

## Options

```
1--verbose                         enable verbose mode
2-f, --prefix <prefix>             filter by module key prefix (e.g. jira:,
3                                  jira:issuePanel, confluence:)
4-p, --product <product>           filter by product (Jira, Jira Service
5                                  Management, Confluence, etc.)
6-u, --ui-type <ui-kit|custom-ui>  filter by UI framework (ui-kit, custom-ui)
7--non-interactive                 run the command without input prompts
8-h, --help                        display help for command
9
```
