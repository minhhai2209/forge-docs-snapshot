# version list

## Description

returns a summary of all major versions of the app. Summary includes:

* version number
* deployment date
* egress
* analytics
* policies
* scopes
* connect keys
* functions
* remotes
* modules
* license

## Usage

```
1Usage: forge version list [options]
2
```

## Options

```
1--verbose                        enable verbose mode
2-e, --environment [environment]  specify the environment (see your default
3                                 environment by running forge settings list)
4--non-interactive                run the command without input prompts
5--json                           output results in JSON format
6-f, --out-file <outFile>         specify a file to output the results
7-h, --help                       display help for command
8
```
