# module

## Description

[Preview] Commands for managing modules in your app. ⚠️ These commands may
modify your app files (manifest.yml, source files, and package.json).

## Usage

```
1Usage: forge module [options] [command]
2
```

## Options

```
1--verbose                    enable verbose mode
2-h, --help                   display help for command
3
```

## Commands

```
1add [options]                [Preview] add a module to your Forge App. ⚠️ This
2                             will modify your app files (manifest.yml, source
3                             files, and package.json).
4list [options]               [Preview] list available module templates
5show [options] [moduleType]  [Preview] show details about a module template
6
```
