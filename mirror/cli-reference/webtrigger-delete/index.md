# webtrigger delete

## Description

delete a webtrigger URL

## Usage

```
1Usage: forge webtrigger delete [options]
2
```

## Options

```
1--verbose                          enable verbose mode
2-i, --webtriggerId <webtriggerId>  ID of the webtrigger URL to delete
3-s, --site [site]                  site URL (example.atlassian.net)
4-p, --product [Atlassian app]      Atlassian app (Jira, Confluence, Compass,
5                                   Bitbucket)
6-e, --environment [environment]    specify the environment (see your default
7                                   environment by running forge settings list)
8-h, --help                         display help for command
9
```
