# manifest render

## Description

render the app manifest after applying environment transformations

## Usage

```
1Usage: forge manifest render [options]
2
```

## Options

```
1--verbose                        enable verbose mode
2-e, --environment [environment]  specify the environment (see your default
3                                 environment by running forge settings list)
4-p, --placement <placement>      placement where the app is deployed, for
5                                 example a data residency region or Isolated
6                                 Cloud ID
7--json                           output results in JSON format (default:
8                                 false)
9-h, --help                       display help for command
10
```
