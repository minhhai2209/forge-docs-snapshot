# manifest render

## Description

render the app manifest after applying environment transformations

## Usage

```
1
Usage: forge manifest render [options]
```

## Options

```
1
2
3
4
5
6
7
8
--verbose                        enable verbose mode
-e, --environment [environment]  specify the environment (see your default
                                 environment by running forge settings list)
-p, --placement <placement>      placement where the app is deployed, for
                                 example a DaRe region or Isolated Cloud ID
--json                           output results in JSON format (default:
                                 false)
-h, --help                       display help for command
```
