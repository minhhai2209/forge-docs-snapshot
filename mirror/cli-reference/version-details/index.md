# version details

## Description

returns the details of a specific version of the app. Details include:

* egress
* analytics
* policies
* scopes
* connect keys
* functions
* remotes
* modules
* license

## Usage

```
1Usage: forge version details [options]
2
```

## Options

```
1--verbose                        enable verbose mode
2-e, --environment [environment]  specify the environment (see your default
3                                 environment by running forge settings list)
4--non-interactive                run the command without input prompts
5-v, --major-version <version>    specify a major version
6--json                           output results in JSON format
7-f, --out-file <outFile>         specify a file to output the results
8-h, --help                       display help for command
9
```
