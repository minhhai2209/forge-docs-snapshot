# create

## Description

create an app

## Usage

```
1Usage: forge create [options] [name]
2
```

## Options

```
1--verbose                                      enable verbose mode
2-t, --template <template name>                 specify the template to use
3-d, --directory <directory name>               specify the directory to create (uses the template name by default)
4--personal                                     register as a personal app
5-s, --developer-space-id <Developer Space id>  specify the Developer Space id to use
6-y, --accept-terms                             automatically accept terms and conditions in non-interactive mode
7-h, --help                                     display help for command
8
```
