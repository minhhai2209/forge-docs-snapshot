# site

## Description

manage demo sites

## Usage

```
1Usage: forge site [options] [command]
2
```

## Options

```
1--verbose            enable verbose mode
2-h, --help           display help for command
3
```

## Commands

```
1provision [options]  provision a demo site for development and testing
2
```

## Operation

Use `forge site` commands to provision or display the demo development site assigned to your
Atlassian account.

For setup instructions, lifecycle information, and troubleshooting, see
[Provision a demo development site](/platform/forge/provision-a-demo-development-site/).
