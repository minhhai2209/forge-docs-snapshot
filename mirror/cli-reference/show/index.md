# show

## Description

display information about the deployed app's containers and services

## Usage

```
1
Usage: forge show [options] [command]
```

## Options

```
1
2
--verbose             enable verbose mode
-h, --help            display help for command
```

## Commands

```
1
2
3
4
containers [options]  display information about deployed app containers for a
                      given service
help [command]        display help for command
services [options]    display information about deployed app services
```

## Operation

This command is used with Forge Container services, which is now in [Preview](/platform/forge/whats-coming/#forge-preview). Preview features are fully supported but remain under active development and may be subject to shorter deprecation windows.
