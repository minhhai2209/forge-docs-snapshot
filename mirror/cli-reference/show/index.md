# show

## Description

display information about the deployed app's containers and services

## Usage

```
1Usage: forge show [options] [command]
2
```

## Options

```
1--verbose             enable verbose mode
2-h, --help            display help for command
3
```

## Commands

```
1containers [options]  display information about deployed app containers for a
2                      given service
3help [command]        display help for command
4services [options]    display information about deployed app services
5
```

## Operation

This command is used with Forge Container services, which is now in [Preview](/platform/forge/whats-coming/#forge-preview). Preview features are fully supported but remain under active development and may be subject to shorter deprecation windows.
